# 🏛️ Smart Union — Digital Citizen Services & Governance Platform

[![React](https://img.shields.io/badge/React-19.0-61DAFB?style=for-the-badge&logo=react)](https://react.dev/)
[![React PDF](https://img.shields.io/badge/PDF_Renderer-React_PDF-E53935?style=for-the-badge)](https://react-pdf.org/)
[![Handlebars](https://img.shields.io/badge/Templates-Handlebars-f0772b?style=for-the-badge&logo=handlebars.js)](https://handlebarsjs.com/)
[![JWT](https://img.shields.io/badge/Auth-JWT-000000?style=for-the-badge&logo=json-web-tokens)](https://jwt.io/)

A full-scale digital governance and citizen service automation engine designed for local government institutions. Delivers authenticated certificate generation, digitized citizen registries, and institutional administrative dashboards.

---

## 🌟 Core Modules

- **🪪 Official Certificate Engine**: Generates tamper-proof municipal documents using `@react-pdf/renderer` and Handlebars templates.
- **🔒 Cryptographic Security**: JWT token validation, role-based authorization, and bcrypt password hashing.
- **📊 Village & Ward Analytics**: Aggregated population, household, and civic service request reporting.
- **🌐 Citizen Tracking Portal**: Track application lifecycle from submission to administrative sign-off.

---

## 🚀 Setup & Launch

```bash
git clone https://github.com/murshedkoli-2/smart_union.git
cd smart_union
npm install
npm run dev
```
